# DS Always 1.3.0

本版把「窗口随模型动态调整」和「上下文组装最小化改动」从设计稿落成代码，同时把源码仓库公开。

## 仓库与文档

- `kayz/dsalways` 已从私有改为 **公开**（发布前全历史扫描过，无硬编码密钥；`.env` / `dist` / `release` / 日志均在 gitignore）。
- 首页 `README.md` 改为中文项目介绍，含安装版 / 便携版下载地址与最新版入口；上游英文说明保留为 `README.en.md`。
- 设计讨论稿在 `docs/记忆系统设计.md`。

## 动态窗口（按当前模型推导，不给五个模型各配一套参数）

- 未显式设置窗口时**跟随当前模型**（1M 或 164K）。1.2.0 用全局 128K 兜底，导致 1M 模型被提前压缩；老用户首次升级时会做一次性迁移。
- 输出预留先扣：按模型 `max_output`，R1 恒思考额外留一份思维链预算。
- **60% 触发 / 一次压到 40%** 双水位线，长对话不再每轮都触发压缩。
- 压缩提示按原因给外行能看懂的文案：常规「正在整理更早的对话…」、换到小窗模型「为了让新模型接着聊…」、摘要二次精简「正在精简更早的记录…」。

## 上下文组装（省缓存）

- **命中率可见**：每轮把 `cache_read / prompt_tokens` 写进 `timing.log`，助手与上下文面板显示上轮命中率与近 10 轮柱状图。这是后续所有改造的验收基线。
- **记忆搬到尾部**：普通记忆不再整块进 system，改为按当前提问关键词召回 top-k，拼在最后一条用户消息前；只有置顶记忆留在稳定区。system 中段不再随记忆抽取变化。
- **摘要分段定稿**：`summarizeRounds` 从「滚动合并重写」改成「每段独立产出、落盘后不可变」，压缩只追加新段，旧段一个字不改；1.2.0 的旧滚动摘要作为第 0 段整体保留。
- `keepRecent` 默认 10 轮，检索用关键词打分，不引入向量库。
- 历史 `latest_reminder` 快照**维持现状不改**：核查确认它是生成时冻结在消息里的固定字符串，本来就属于可命中的稳定前缀。

## 换到小窗模型时的确认

- 切到窗口更小、且旧摘要超过目标窗口 20% 预算时，弹窗「换个模型，要先整理一下旧对话」，说明不会删记录、不改动最近对话、可能产生几分钱费用。
- **切换延迟生效**：点「先不换，用回原来的模型」时通道与模型都没有落盘，不存在界面与实际不一致。
- 确认后下一次发送才做摘要二次精简（走内部 1M 摘要器），并在进度提示里说明原因。

## 暂缓

- 会话档案（设计稿阶段 4）：自动生成需要一次额外 API 调用且会改动稳定区，与本轮「先拿命中率基线、尽量不动前缀」的目标冲突，等命中率数据出来再评估。分段定稿摘要已缓解超长会话首次压缩慢的问题。
