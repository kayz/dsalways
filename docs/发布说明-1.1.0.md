# DS Always 1.1.0

> 第三方客户端，非 DeepSeek 官方产品。

## 这一版最主要的变化：多了一个模型通道

之前只能用 DeepSeek 官方 Key。现在多了一个可选通道——**硅基流动**，两套 Key 可以同时保存，在「设置 → 模型接入」里切换通道。

考虑多数用户对模型并不熟悉，硅基流动下**只开放三个模型**，不用在几十个名字里挑：

| 模型 | 上下文 | 思考 | 适合什么 |
| --- | --- | --- | --- |
| DeepSeek-V4.1-Flash | 1M | 不能开关 | 默认，最快最便宜，长对话首选 |
| DeepSeek-V3.2 | 164K | 可开关 | 平衡档，需要时开思考 |
| DeepSeek-R1 | 164K | 始终思考 | 难题推理，慢但细 |

选中硅基流动后，**对话框左下角随时切模型**，切完下一条消息就按新模型发，不用回设置页。

## 换了通道之后，这些行为要提前知道

- **上下文窗口按「你设的」和「模型真实的」取小值**。V3.2 和 R1 只有 164K，如果按 1M 去用会被服务端直接拒，所以这里必须收着算。
- **长对话会先整理历史**。首次发送要把早前轮次压成摘要，可能几十秒。这一版起输入框上方会显示「**正在找回之前的对话…（已整理 2/5 段）**」，而不是让你对着转圈猜。
- **硅基流动只提供纯对话**。附件、联网搜索、自动标题、语音输入与朗读都依赖官方通道，切过去后这些入口会被禁用并给出文案提示；切回官方通道即可恢复。
- **摘要与记忆这类后台请求固定走最便宜的 V4.1-Flash**，不跟随你选的模型——用 R1 做机械摘要又慢又贵。

## 前置指令（会话可选）

「设置 → 模型接入」里可以填一段文本，注入到 system 最前面（人格、记忆、摘要之前），默认关闭。每个会话在输入框工具栏还有**独立开关**，会话之间互不影响。

## 其它修复

- 硅基流动请求在桌面端直接 `Failed to fetch` 的问题：带 `Authorization` 的请求会先发 OPTIONS 预检，而服务端不一定回 CORS 头，现在由主进程改写预检并补全 `Allow-Headers` / `Allow-Methods`。
- R1 按官方建议不加 system，指令并进第一条用户消息；`enable_thinking` 只发给 V3.2，其它模型不传，避免被服务端拒绝。
- 拿到 `finish_reason` 但没收到 `[DONE]` 也按完整回答处理，不误判成断流触发续写。

## 升级方式

安装版会自动发现新版本：设置 → 关于与更新 → 下载更新 → 重启并安装（后台静默装完自动重开）。免安装版不支持自动更新，需重新下载。

## 已知限制

- 导入是覆盖式，一次导入会替换全部本地对话。
- 未做代码签名，安装时 Windows SmartScreen 可能提示「未知发布者」。
- 断流续写最多 2 次；思考中途断（无签名）时无法续写，界面会明确提示。
