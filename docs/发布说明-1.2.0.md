# DS Always 1.2.0

> 第三方客户端，非 DeepSeek 官方产品。

这一版把模型选择统一了：**5 个模型放在同一个下拉里，选模型就等于选通道**，并且随时能看清当前是哪个渠道的哪个模型。

## 一个下拉，五个模型

输入框左下角的模型下拉现在是这样（左边是说明，界面里带勾的是当前项）：

```
官方 · V4 Flash
官方 · V4 Pro          ← 1.2.0 新增
硅基流动 · V4.1 Flash
硅基流动 · V3.2
硅基流动 · R1
```

- **标签带通道前缀**，不用记哪个模型属于哪个渠道；触发器上直接显示「官方 · V4 Pro」这样的完整选中项。
- **选到别的渠道的模型会自动切通道**，不需要先回设置改通道再回来选模型。
- 目标渠道**还没填 Key** 时，会自动打开「设置 → 模型接入」，把 Key 输入框摆在你面前，而不是等发送时才报错。

## 官方通道新增 V4 Pro

官方接口的 `model` 只接受两个值，两个都是 1M 上下文、都支持深度思考开关：

| 模型 | 上下文 | 说明 |
| --- | --- | --- |
| V4 Flash（`deepseek-flash`） | 1M | 默认。速度快、价格低 |
| V4 Pro（`deepseek-v4-pro`） | 1M | 旗舰推理，约 3 倍价格、并发更低 |

设置页的「当前模型」会写成「官方 · V4 Pro · 上下文 1M · 旗舰推理，更贵更慢」，「切换模型」把两个渠道的模型分两行列全。

## 一致性细节

- 每条回复都会把自己用的模型记在消息里，**重新生成 / 续写沿用那条回复当时的模型**，中途换模型不会让一段回答前后不一致。
- 上下文窗口按「你设的上限」和「模型真实窗口」取小值；两个官方模型和硅基流动的 V4.1 Flash 都是 1M，V3.2 / R1 是 164K。
- 摘要与记忆这类后台请求仍然固定走最便宜的 `deepseek-flash`（官方）/ V4.1 Flash（硅基流动），不跟随你选的模型。

## 同时包含 1.1.1 的修复

- 选「DeepSeek 官方」时不再出现硅基流动的注册链接与能力说明。
- 模型信息行不再重复报上下文窗口。

## 升级方式

安装版：设置 → 关于与更新 → 下载更新 → 重启并安装（静默安装后自动重开）。免安装版请重新下载。
