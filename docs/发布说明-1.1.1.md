# DS Always 1.1.1

> 第三方客户端，非 DeepSeek 官方产品。

1.1.0 上线后立刻修的两处界面问题，功能本身与 1.1.0 相同（硅基流动通道、三模型切换、压缩提示、前置指令）。

## 修了什么

- **选「DeepSeek 官方」时，下面还会带出硅基流动的内容**：注册链接与「硅基流动只提供对话」的说明之前是无条件渲染的，现在只在选中硅基流动时出现。
- **没填硅基流动 Key 也能看到 V3.2 / R1 的模型选择**：现在要先保存 Key，设置页才出现「当前模型 / 切换模型」，输入框工具栏的模型下拉同理——没有 Key 时切模型没有意义。
- **模型信息行重复报窗口大小**（「V3.2 · 上下文 160K · 164K 上下文…」）：上下文只由「上下文 160K」这处给出，后面的说明改为只讲能力（可开关深度思考 / 始终思考）。

## 升级方式

安装版会自动发现新版本：设置 → 关于与更新 → 下载更新 → 重启并安装。免安装版请重新下载。
